# こえだしランド（マイク修正版）

発声・発音練習アプリ「こえだしランド」の、マイクが起動しない問題を直した版です。

- アプリとして開く: https://kawaitomohiro.github.io/koedashi-land/
- コード: このリポジトリの `index.html`（1ファイルで完結）

## マイクの許可が出なかった原因

AppSheet などのアプリの中（埋め込み枠・アプリ内ブラウザ）で開くと、マイクが止められていて「許可しますか？」が出ません。
Safari（iPad）か Chrome で、https のURLを直接開いてください。

## 修正した所

1. マイクが使えないとき、理由を画面の赤い帯に出す（アプリの中で止められている／許可しないになっている など）
2. ホームに「マイクをためす」ボタン
3. 「ブラウザでひらく」は `APP_URL` に書いた公開URLを開く（自分で公開するときはこの1行を書きかえる）
4. 音声認識の間は音量メーターのマイクを止める（Android でマイクを取り合って認識が返らない問題）
5. ボタンを押した瞬間に音声認識を始める（iPad の Safari は押した直後でないと許可画面を出さない）
6. 認識結果は「雨・アメ・あめ」のどれでも合格。こえタイピングは画面のことばと合ったときだけ得点
7. パタカれんだの回数を数える（声の大きさの山を1回と数える）
8. 誤字（のどもの奥 など）・や行の「らいおん」・フォントの読み込みを修正
